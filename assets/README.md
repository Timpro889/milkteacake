# 自制素材替换说明

把图片放进本目录（`milktea/assets/`）即可自动替换程序化绘制的贴图。
**没有放图的物品会继续用内置绘制**，所以可以只替换其中几个。

### 顾客头像（独立一组，可单独替换）

订单卡最左侧的大圆头像就是顾客。**一共 12 个**，每次来的顾客从这 12 种里随机抽，且**同一时间挂出的订单不会重复出现同一种形象**。

| 文件名 | 顾客 | 在卡内显示直径（设计像素） |
|---|---|---|
| `cus0.png` | 顾客 0 | 192（1 物品单）/ 166（2 物品）/ 104（3 物品） |
| `cus1.png` ~ `cus11.png` | 顾客 1~11 | 同上 |

少放几张也没关系，没放的那几个会自动用内置绘制的顾客形象兜底。

支持 `png` / `webp` / `jpg`（按此顺序查找，第一个能读到的生效）。

### 奶茶杯品牌 LOGO（独立一组，叠加在所有奶茶杯上）

你**不需要替换整杯奶茶**，只要放一张小图标，程序会自动把它烙印到**每一档奶茶杯子**上（内置绘制的杯子、以及你自己替换的 `tea1~tea8.png` 都会带上）。

| 文件名 | 作用 | 备注 |
|---|---|---|
| `logo.png` | 奶茶杯上的品牌 LOGO | 透明背景最佳；位置/大小用 `config.js` 里的 `brand` 调节 |

- **尺寸建议：正方形 256×256 或 512×512**，带透明通道（PNG 最佳）。LOGO 会被等比缩放到「杯子半径 R 的 `scale` 倍」后贴在杯身。
- **贴图位置**：默认贴在杯身中下部、水平居中（`brand.dy = 0.15`，正值偏下；想往上挪就调小或设负值）。
- **调参入口**在 `milktea/js/config.js` 的 `brand`：

```js
const brand = {
  logoFile: 'logo',   // 改成 '' 即可关闭 LOGO 叠加
  scale: 0.50,        // LOGO 宽度 = 杯子半径 R 的倍数，越大越显眼
  dx: 0.0,           // 水平偏移（右为正），单位 = R
  dy: 0.15,          // 垂直偏移（下为正），单位 = R
};
```

- 控制台执行 `Art.customReport()`，返回里多了 `logo` 字段：`'loaded'` 已生效、`'missing'` 没读到图、`'disabled'` 已关闭。


## 2. 尺寸与格式

- **画布：正方形，统一 512×512**。不要按上表「贴图边长」分别裁切 —— 那一列只是它进游戏后占用多少屏幕空间，程序会自动缩放。
- **格式：PNG-24 带 Alpha 通道**（推荐）或 WebP。**不要用 JPG**：没有透明通道，会带一圈白底。
- 512 已经高于实际需要（手机上最大物体约 309 物理像素），再大只会拖慢加载。
- **顾客头像 `cus0~cus11.png` 同样 512×512 正方形**（共 12 张）。**脸要放在正中央**，因为游戏里会裁成圆形显示（圆外部分被切掉）。背景**建议不透明**（纯色或场景都行），透明角落会被圆形裁掉，不用担心白边。头像不需要遵守「92.6% 安全圈」规则，可以画满整张正方形。

## 3. 构图规则（重要）

1. **物体主体画到画布宽度的 92.6%**，四周留约 19px 透明边。
   程序化贴图自带这圈内边距，视觉直径正好等于碰撞圆。如果内容撑满 100%，物品会看起来比实际碰撞范围大一圈，出现「明明碰上了却没合成」或反过来「没碰上就弹开」。
2. **内容居中**。渲染是 `drawImage(img, x-size/2, y-size/2, size, size)`，锚点固定在几何中心，偏了会歪。
3. **底部要有"落地感"**：物体底部是接触面，游戏会在下方叠一层接触阴影。图片本身不要再画大片投影，否则会和代码阴影叠成脏斑。
4. **视角：略微俯视**（能看到一点点杯口/盘面），和桌面倾斜角一致。

## 4. 怎么确认生效

打开游戏后，浏览器控制台执行：

```js
Art.customReport()
// { loaded: ["tea1", "cake3"], missing: ["tea2", ...] }
```

`loaded` 里的就是成功替换的。菜单图标、订单卡、桌面物品会同时更新。

## 5. 模板图目录（已移出 `assets/`）

14 张「当前程序内置贴图导出的 512×512 PNG」模板，现已移到工作区根目录下的
`_milktea_extra/assets__template/`（移出是为了让发布包保持在 5.5MB，不上传多余文件）。
里面已经符合上述构图规则，直接在上面改是最省事的方式 —— 保持画布尺寸和内容占比，
替换掉画面内容即可。改完把文件放进 `assets/` 并以 `tea1~8.png` / `cake1~6.png` 命名才会生效。
